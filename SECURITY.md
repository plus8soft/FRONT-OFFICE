# Security Policy

## Supported Versions

Security fixes are provided for the latest version on the `main` branch.

## Reporting a Vulnerability

Please **do not** report security issues via public GitHub issues, discussions, or pull requests.

Instead, report vulnerabilities privately by emailing:

- `support@plus8soft.com`

Include as much information as possible:

- A clear description of the issue and its impact
- Steps to reproduce (proof-of-concept if available)
- Affected component/module and version/commit
- Any suggested fix or mitigation (if you have one)

We will acknowledge receipt and coordinate a fix and disclosure timeline.
